1.2 Missing Values

Missing values occur when some attribute values are not recorded.

titanic[[
    "age",
    "embarked",
    "deck",
]].isna().sum()
age         177
embarked      2
deck        688
dtype: int64
plot_missing_counts(
    titanic
)

For a numerical attribute, one simple approach is to replace missing values with the median.

titanic_clean = titanic.copy()

age_median = titanic_clean["age"].median()

titanic_clean["age"] = (
    titanic_clean["age"]
    .fillna(age_median)
)

print(
    "Missing age:",
    titanic_clean["age"].isna().sum(),
)
Missing age: 0

For a categorical attribute such as embarked (S, C, Q), the median is not defined. A common replacement is the mode, the most frequent value. Together with the mean and the median, it is one of the three standard measures of central tendency.

Series.mode() returns that most frequent value. If several values are tied, it returns all of them; the code below uses the first.

TipThink

Why do age and embarked use different replacement values?
age is numerical, so the median is defined. embarked is categorical, so the median is not defined and we use the mode, the most frequent value.

1.4 Outliers

An outlier is an unusually small or large value.

A common rule uses the interquartile range (IQR).

\[ IQR = Q_3 - Q_1 \]

Values outside the following range are considered potential outliers:

\[ [Q_1 - 1.5IQR,\; Q_3 + 1.5IQR] \]

We use Titanic fare and first obtain the first and third quartiles.

fare = (
    titanic["fare"]
    .dropna()
)

q1 = fare.quantile(0.25)
q3 = fare.quantile(0.75)

print(
    "Q1:",
    round(q1, 2),
)

print(
    "Q3:",
    round(q3, 2),
)
Q1: 7.91
Q3: 31.0
ImportantQ. Practice

Implement iqr_outlier_bounds() in lab02_1.py. It should return the lower and upper fences from q1 and q3.

Hint: Use q3 - q1 for the IQR.

lower, upper = iqr_outlier_bounds(
    q1,
    q3,
)

outlier_mask = (
    (fare > upper)
    | (fare < lower)
)

print(
    "Lower threshold:",
    round(lower, 2),
)

print(
    "Upper threshold:",
    round(upper, 2),
)

print(
    "Potential outliers:",
    int(outlier_mask.sum()),
)

TipThink

Does a statistical outlier always mean that the recorded value is wrong?
No. The IQR rule only flags values far from the bulk of the data. An unusual fare can still be a real first-class ticket.

1.5 Aggregation

Aggregation combines two or more objects into a single higher-level object.

Objects with the same grouping value are combined into one summary record.

For example, we can group passengers by pclass and summarize survived and fare.

class_summary = (
    titanic
    .groupby("pclass")
    .agg({
        "survived": "mean",
        "fare": "median",
    })
    .reset_index()
)

class_summary
pclass survived fare
0 1 0.629630 60.2875
1 2 0.472826 14.2500
2 3 0.242363 8.0500

Each row now represents one passenger class rather than one passenger.

TipThink

Why can stratified sampling be useful when some groups contain much fewer objects than others?
Simple random sampling can miss small groups. Stratified sampling draws from each group, so rare classes still appear in the sample.
