Byungkook Oh

Overview

In this lab, we use Iris and Moons to examine three questions:

  1. How does an \(\epsilon\)-graph decide which pairs become edges?
  2. How does a kNN graph select neighbors, and why can a node’s degree exceed \(k\)?
  3. How do heat-kernel weights decay as Euclidean distance grows?

3.2 Constructing a Nearest Neighbor Graph

The graph is constructed in three steps:

  1. create a node for each object,
  2. connect nearby objects,
  3. assign edge weights.

Step 1. Create Nodes

Each Iris object becomes one node.

print(
    "Number of nodes:",
    len(X_iris),
)
Number of nodes: 150

Step 2. Create Edges

We first use a small distance matrix to see how each graph is constructed.

D_small = np.array([
    [0.0, 0.2, 0.8],
    [0.2, 0.0, 0.5],
    [0.8, 0.5, 0.0],
])

D_small
array([[0. , 0.2, 0.8],
       [0.2, 0. , 0.5],

\(\epsilon\)-Graph

Connect \(O_i\) and \(O_j\) when

\[ d(O_i,O_j) \le \epsilon. \]

For example, with \(\epsilon=0.4\):

epsilon_small = 0.4

A_small_epsilon = (
    D_small
    <= epsilon_small
)

np.fill_diagonal(
    A_small_epsilon,
    False,
)

A_small_epsilon
array([[False,  True, False],
       [ True, False, False],
       [False, False, False]])

True indicates that the two objects are connected.

TipThink

Why can different objects have different numbers of neighbors in an \(\epsilon\)-graph?
\(\epsilon\) is a fixed radius. A point in a dense region has many neighbors inside that radius; a point in a sparse region has few.

kNN Graph

If \(O_j\) is among the \(K\) nearest neighbors of \(O_i\), add

\[ O_i \rightarrow O_j. \]

For the same distance matrix, use \(K=1\):

K_small = 1
n_small = D_small.shape[0]

A_small_knn_directed = np.zeros(
    (n_small, n_small),
    dtype=bool,
)

for i in range(n_small):
    distances = D_small[i].copy()
    distances[i] = np.inf

    neighbors = (
        np.argsort(distances)[:K_small]
    )

    A_small_knn_directed[
        i,
        neighbors,
    ] = True

A_small_knn_directed
array([[False,  True, False],
       [ True, False, False],
       [False,  True, False]])

Each row shows the nearest-neighbor edge selected from one object. The direction is often ignored.

A_small_knn = (
    A_small_knn_directed
    | A_small_knn_directed.T
)

A_small_knn
array([[False,  True, False],
       [ True, False,  True],
       [False,  True, False]])

TipThink

Why can a node have more than \(K\) neighbors after direction is ignored?
kNN is directed. If \(A\) lists \(B\) as a neighbor, the undirected graph keeps the edge even when \(A\) is not among \(B\)’s \(K\) nearest. Extra incoming edges raise the degree above \(K\).

Step 3. Heat-Kernel Weights

For each pair,

\[ w_{ij} = \exp \left( -\frac{d(O_i,O_j)^2} {t^2} \right). \]

Here, \(t\) controls how quickly similarity decreases with distance.

Because D_iris contains Euclidean distances, the heat-kernel similarity matrix is computed directly from D_iris.

t = 1.0

W = np.exp(
    -(D_iris ** 2)
    / (t ** 2)
)

    W[:6, :6]
).round(3)

TipThink

What happens to \(w_{ij}\) as the Euclidean distance increases?
The heat-kernel weight decays toward 0. Distant pairs contribute almost no similarity.

TipThink

How do the \(\epsilon\)-graph and kNN graph differ in selecting neighbors?
The \(\epsilon\)-graph uses a distance threshold, so the number of neighbors varies. The kNN graph uses a neighbor count, so each node has \(K\) outgoing neighbors.
